# Portafolio de Nicolás Vrancovich

Página estática: `index.html` (CSS y JavaScript embebidos) y la carpeta `img/` con las imágenes.

## Publicar en GitHub Pages

1. Subí el contenido de esta carpeta a la rama `main` del repositorio.
2. En GitHub, abrí **Settings** > **Pages**.
3. En **Source** elegí **Deploy from a branch**, rama `main`, carpeta `/ (root)`, y guardá.
4. Esperá un par de minutos. El sitio queda en `https://nvranco.github.io` si el repositorio se llama `nvranco.github.io`, o en `https://nvranco.github.io/<nombre-del-repo>/` si tiene otro nombre.
